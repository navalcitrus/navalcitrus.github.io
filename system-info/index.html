System Info

This system is Naval Citrus; perhaps I am Naval Citrus.

The purpose of Naval Citrus is dually to communicate topics I find interesting and act as a forcing function for me to write about those topics. I don’t claim to have anything especially novel to say in any given area, but my hope is that someone might find ideas more approachable through my writing.

If you notice anything which is incorrect or poorly explained, please do not hesitate to reach out to me .

Naval Citrus has been operational since January Fourth 2026 and runs on a temporary software stack:

Purpose Tool Planned
Web apps Rust -> WASM + Small TS
Webgit GitHub cgit
Host GitHub Pages nginx
Markdown Manager Obsidian
Version Control Git
Config – Ansible + Nix
Registrar / DNS Cloudflare
HTML Generator Hugo
Hugo Theme naval-citrus-theme

All webapps hosted on Naval Citrus can be found on my GitHub . If you find any of my code useful, feel free to do whatever you like with it; if you’re feeling kind and generous, give me a shout-out when you do.
